개인정보 처리방침

업데이트: 2026년 10월 2일

요약: 영화와 영상은 절대 컴퓨터 밖으로 나가지 않습니다. Pop3D는 앱을 개선하기 위해 익명 사용 통계(그래픽 카드 모델, 성능 등)만 보내며, 언제든지 설정에서 끌 수 있습니다.

운영자 소개

Pop3D는 2D 영상을 VR 헤드셋용 3D로 바꿔 주는 무료 앱입니다. 컴퓨터 앱(Windows)과 헤드셋 앱(Meta Quest)으로 이루어져 있으며, 이 방침은 두 앱 모두에 적용됩니다.

절대 수집하지 않는 정보

  • 영화와 영상의 이름, 내용, 이미지, 그리고 컴퓨터 화면에 표시되는 내용.
  • 컴퓨터에 있는 폴더와 파일의 이름.
  • 이름, 계정, 연락처 등 사용자를 식별할 수 있는 모든 정보(이메일 주소는 사용자가 직접 제안에 입력한 경우에만 해당. 아래 참고).
  • IP 주소: 저장하지 않으며 위치를 알아내는 데 쓰지 않습니다.
  • 카메라 이미지, 주변 환경, 헤드셋의 움직임.

모든 처리는 사용자의 컴퓨터에서 이루어집니다. 영상은 로컬 네트워크(Wi-Fi 또는 케이블)를 통해 컴퓨터에서 헤드셋으로 전달되며, 인터넷을 거치지 않습니다.

수집하는 정보(익명 사용 통계)

문제를 찾고 더 많은 컴퓨터에서 앱을 더 빠르게 만들기 위해, 컴퓨터 앱은 다음과 같은 기술 정보를 보냅니다.

  • 설치 시 만들어지는 무작위 코드로, 사용자와는 아무 관련이 없습니다(설치 수를 중복 없이 세는 데만 사용).
  • Pop3D와 Windows 버전, 시스템과 앱의 언어.
  • 그래픽 카드 모델, 비디오 메모리, 드라이버 버전, 프로세서, RAM.
  • 성능 결과: 초당 프레임 수, 그래픽 카드 사용률, 선택한 화질.
  • 앱 사용 방식: 헤드셋과 연결 방식(Wi-Fi, 케이블, PC VR), 영상 모드(2D, 3D, PC 화면), 사용 시간.
  • 설치 단계와 오류 메시지(파일·폴더 이름 제외). 오류가 나거나 영상이 멈추면 앱 기술 로그의 마지막 몇 줄도 함께 보내며, 컴퓨터를 떠나기 전에 정리됩니다. 영화·파일·폴더 이름, 이메일 주소, IP 주소는 포함되지 않습니다.

이 정보는 분석 서비스 PostHog가 유럽연합 내 서버에 저장하며, Pop3D 팀만 볼 수 있습니다. 이 정보를 판매하거나 다른 누구와도 공유하지 않으며, 광고에 사용하지 않습니다.

보내 주신 제안

앱의 아이디어와 의견에서 메시지를 보낼 수 있습니다. 작성한 내용과 함께 앱 버전과 그래픽 카드 모델이 전송됩니다. 이메일은 선택 사항이며, 입력한 경우에만 전송되고 메시지에 답장하는 데만 사용됩니다. 제안은 통계와 같은 서비스(PostHog, 유럽연합)에 저장됩니다. 사용자가 직접 보내기로 한 것이므로 통계를 꺼 두어도 전송됩니다.

끄는 방법

컴퓨터 앱에서 설정을 열고 익명 사용 데이터 보내기를 끄세요. 그 이후로는 아무것도 전송되지 않습니다(직접 보내기로 한 제안 제외).

업데이트

Pop3D는 실행될 때 GitHub(버전이 게시되는 곳)에서 새 버전이 나왔는지 확인합니다. 다른 웹사이트와 마찬가지로 이때 GitHub는 컴퓨터의 인터넷 주소를 받게 되며, 이 확인에는 GitHub의 개인정보 처리방침이 적용됩니다. 사용자의 정보는 함께 전송되지 않습니다.

헤드셋 앱(Meta Quest)

Pop3D 헤드셋 앱은 어떤 정보도 수집하지 않으며 인터넷으로 아무것도 보내지 않습니다. 영상을 받고 컨트롤러 입력을 보내기 위해 로컬 네트워크에서 컴퓨터와만 통신합니다.

아동

Pop3D는 아동을 포함해 누구의 개인정보도 수집하지 않습니다. 헤드셋 제조사의 권장 연령을 따라 주세요.

사용자의 권리(GDPR 및 LGPD)

통계는 익명이므로 사용자와 연결할 수 없습니다. 그래도 컴퓨터의 통계나 보낸 제안의 삭제를 원하시면, 설정에 표시되는 설치 코드를 적어 아래 링크로 연락해 주세요.

방침 변경

이 방침이 바뀌면 업데이트 날짜와 함께 새 버전이 이 페이지에 게시됩니다.
