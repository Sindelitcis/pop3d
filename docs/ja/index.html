Meta Quest 用 Pop3D アプリ

Meta Horizon Store で入手

USB ケーブルでインストールすることもできます：

  1. スマートフォンで Meta Horizon アプリを開き、デバイス › ヘッドセットの設定で開発者モードをオンにします。Meta の開発者アカウント（無料）が必要です。
  2. Quest を USB ケーブルでパソコンにつなぎます。
  3. パソコンの Pop3D で Settings › Headset を開き、Install on Quest をクリックして、ヘッドセットの中で許可をタップします。これで完了！

よくある質問

本当に無料ですか？

はい。広告なし、サブスクなし、落とし穴もありません。

先に動画を変換する必要はありますか？

いいえ。再生するだけで、観ている間に 3D になります。

ヘッドセットに何かインストールする必要はありますか？

必須ではありません。いちばん簡単なのは Quest 用 Pop3D アプリで、Meta のストアで無料で入手できます。Steam Link、Air Link、Virtual Desktop、SteamVR でも使えます。

Quest 用アプリだけ入れました。次は？

Quest 用アプリは、パソコンの Pop3D が用意した映像を表示します。Windows パソコンにも Pop3D を入れてください。両方を開けば、ヘッドセットがパソコンを自動で見つけます。

インストールはすぐ終わりますか？

初回は約 4 GB をダウンロードします。魔法を生み出す人工知能で、お使いのグラフィックボードに合わせて調整されます。かかる時間は回線しだいです。その後は数秒で起動し、自動で更新されます。

動画配信サービスでも使えますか？

YouTube やほとんどのウェブサイトなど、パソコンの画面に映るものなら使えます。ただし一部の有料サービスはコピー防止のため、どのソフトにも映像の取り込みを許していません。パソコン内の動画ならすぐに使えます。

NVIDIA 以外のグラフィックボードでも動きますか？

今のところ、魔法には NVIDIA RTX グラフィックボードが必要です。搭載していない場合は、何もダウンロードする前に、インストーラーが最初にお知らせします。

動画がパソコンの外に送られることはありますか？

ありません。処理はすべてパソコンの中で行われ、映像は家のネットワークを通ってヘッドセットへ直接届きます。Pop3D が送るのは改善のための匿名の利用統計だけで、Settings（設定）でオフにできます。詳しくはプライバシーポリシーをご覧ください。

アプリは日本語に対応していますか？

このサイトは日本語ですが、Pop3D のアプリは今のところ英語で表示されます。

「Windows によって PC が保護されました」と表示されました。

Microsoft がまだ知らない新しいソフトに対して Windows が出す、標準の警告です。詳細情報をクリックしてから、実行をクリックしてください。

Pop3D へのアイデアがあります！

ぜひ聞かせてください！アプリの Ideas & feedback から直接送れます。Pop3D は生まれたばかりで、使ってくれる人と一緒に成長していきます。

すべてを 3D で観る準備はできましたか？

無料。インストールは自動。ヘッドセットですぐ使えます。
