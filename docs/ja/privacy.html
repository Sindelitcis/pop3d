プライバシーポリシー

更新日 2026年10月2日

要約：あなたの映画や動画がパソコンの外に出ることはありません。Pop3D が送るのは、アプリを改善するための匿名の利用統計（グラフィックボードの型番や性能など）だけで、Settings（設定）からいつでもオフにできます。

運営者について

Pop3D は、2D 動画を VR ヘッドセット向けの 3D に変える無料アプリです。パソコン用アプリ（Windows）とヘッドセット用アプリ（Meta Quest）からなり、本ポリシーはその両方に適用されます。

収集しないもの

  • 映画や動画のタイトル、内容、映像、およびパソコンの画面に表示されるもの。
  • パソコン内のフォルダ名やファイル名。
  • お名前、アカウント、連絡先など、あなたを特定できる情報（メールアドレスは、ご自身で提案に書き込んだ場合のみ。下記参照）。
  • IP アドレス：保存せず、所在地の特定にも使いません。
  • カメラの映像、周囲の環境、ヘッドセットの動き。

処理はすべてあなたのパソコンの中で行われます。映像はローカルネットワーク（Wi-Fi またはケーブル）を通ってパソコンからヘッドセットへ届き、インターネットを経由することはありません。

収集するもの（匿名の利用統計）

問題を見つけ、より多くのパソコンでアプリを速くするために、パソコン用アプリは次のような技術情報を送信します。

  • インストール時に作られるランダムなコード。あなたとは無関係です（インストール数を重複なく数えるためだけに使います）。
  • Pop3D と Windows のバージョン、システムとアプリの言語。
  • グラフィックボードの型番、ビデオメモリ、ドライバーのバージョン、プロセッサー、メモリ（RAM）。
  • 性能の結果：1 秒あたりのフレーム数、グラフィックボードの使用率、選ばれた画質。
  • アプリの使われ方：ヘッドセットと接続の種類（Wi-Fi、ケーブル、PC VR）、映像モード（2D、3D、パソコンの画面）、利用時間。
  • インストールの段階とエラーメッセージ（ファイル名やフォルダ名は含みません）。エラーや映像の停止が起きたときは、アプリの技術ログの最後の数行も送られますが、パソコンを出る前に整理され、映画名、ファイル名、フォルダ名、メールアドレス、IP アドレスは含まれません。

これらのデータは分析サービス PostHog によって欧州連合内のサーバーに保存され、Pop3D チームだけが閲覧します。データを販売したり第三者と共有したりすることはなく、広告にも使いません。

お寄せいただく提案

アプリ内の Ideas & feedback からメッセージを送れます。書いた文章と一緒に、アプリのバージョンとグラフィックボードの型番が送られます。メールアドレスは任意で、入力した場合のみ送られ、返信のためだけに使います。提案は統計と同じサービス（PostHog、欧州連合）に保存されます。ご自身で送ると決めたものなので、統計をオフにしていても送信されます。

オフにする方法

パソコン用アプリで Settings（設定）を開き、Send anonymous usage data をオフにしてください。それ以降は何も送信されません（ご自身で送る提案を除きます）。

アップデート

Pop3D は起動時に GitHub（バージョンを公開している場所）を確認し、新しいバージョンが出ているかを調べます。ほかのウェブサイトと同じく、その際に GitHub はパソコンのインターネット上のアドレスを受け取ります。この確認には GitHub のプライバシーポリシーが適用されます。あなたの情報が一緒に送られることはありません。

ヘッドセット用アプリ（Meta Quest）

ヘッドセット用の Pop3D アプリは、データを収集したり、インターネットに送ったりしません。映像を受け取り、コントローラーの操作を送るために、ローカルネットワーク内であなたのパソコンとやり取りするだけです。

お子さまについて

Pop3D は、お子さまを含め、誰の個人データも収集しません。ヘッドセットのメーカーが定める対象年齢に従ってください。

あなたの権利（GDPR・LGPD）

統計は匿名のため、あなたと結びつけることはできません。それでも、お使いのパソコンの統計や、送った提案の削除をご希望の場合は、Settings に表示されるインストールコードを添えて、下記のリンクからご連絡ください。

本ポリシーの変更

本ポリシーを変更した場合は、更新日とともにこのページに新しい内容を掲載します。
