你也可以透過 USB 線安裝：

  1. 在手機上打開 Meta Horizon 應用程式，到「裝置 › 頭戴裝置設定」開啟開發人員模式。Meta 會要求一個免費的開發人員帳號。
  2. 用 USB 線把 Quest 連接到電腦。
  3. 在電腦上的 Pop3D 打開 Settings › Headset，按 Install on Quest，再在頭戴裝置裡點選允許（Allow）。完成！

常見問題

真的免費嗎？

是的。沒有廣告、沒有訂閱、沒有陷阱。

要先把影片轉檔嗎？

不用。按下播放就好：3D 會在你觀看時即時產生。

需要在頭戴裝置上安裝東西嗎？

可裝可不裝。Quest 版 Pop3D 應用程式是最簡單的方式，在 Meta 商店免費提供。你也可以搭配 Steam Link、Air Link、Virtual Desktop 和 SteamVR 使用。

我只裝了 Quest 應用程式，接下來呢？

Quest 應用程式顯示的是電腦上的 Pop3D 準備好的畫面。請也在 Windows 電腦上安裝 Pop3D：兩邊都開啟後，頭戴裝置會自動找到電腦。

安裝很快嗎？

第一次安裝時，Pop3D 會下載約 4 GB：這是施展魔法的人工智慧，並會針對你的顯示卡調整。所需時間取決於你的網路速度。之後幾秒就能開啟，並會自動更新。

可以用在串流平台上嗎？

電腦螢幕上出現的內容都可以，例如 YouTube 和大多數網站。有些付費服務會保護影片防止複製，不讓任何程式擷取畫面。電腦裡的影片則可以直接使用。

沒有 NVIDIA 顯示卡能用嗎？

目前魔法需要 NVIDIA RTX 顯示卡。如果你的電腦沒有，安裝程式會在一開始、下載任何東西之前就告訴你。

我的影片會離開電腦嗎？

永遠不會。一切都在你的電腦上完成，影片透過家中網路直接傳到頭戴裝置。Pop3D 只會傳送匿名的使用統計來持續改進，你也可以在 Settings（設定）中關閉。請參閱隱私權政策。

應用程式有中文版嗎？

這個網站有中文版，但 Pop3D 應用程式目前以英文顯示。

Windows 顯示「Windows 已保護您的電腦」，怎麼辦？

這是 Windows 對 Microsoft 還不認識的新程式顯示的標準警告。請按其他資訊，再按仍要執行。

我對 Pop3D 有個點子！

太好了！在應用程式的 Ideas & feedback 裡就能直接傳給我們。Pop3D 才剛誕生，會跟著使用它的人一起成長。

準備好用 3D 看一切了嗎？

免費。自動安裝。在你的頭戴裝置上就能用。
