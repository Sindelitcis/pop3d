隱私權政策

更新日期 2026年10月2日

重點摘要：你的電影和影片永遠不會離開你的電腦。Pop3D 只會傳送匿名的使用統計（例如顯示卡型號和效能），讓我們改進應用程式，你也可以隨時在 Settings（設定）中關閉。

關於我們

Pop3D 是一款免費應用程式，能把 2D 影片轉成 VR 頭戴裝置用的 3D。它包含電腦應用程式（Windows）和頭戴裝置應用程式（Meta Quest），本政策適用於兩者。

我們絕不收集的資料

  • 你的電影和影片的名稱、內容或畫面，以及電腦螢幕上顯示的任何內容。
  • 電腦中資料夾和檔案的名稱。
  • 你的姓名、帳號、聯絡人或任何能識別你的資料（電子郵件地址只有在你自己填進建議時才會傳送，見下文）。
  • 你的 IP 位址：不會被儲存，也不會用來找出你的所在位置。
  • 攝影機畫面、你周圍的環境或頭戴裝置的動作。

所有處理都在你自己的電腦上進行。影片透過你的區域網路（Wi-Fi 或線材）從電腦傳到頭戴裝置，絕不經過網際網路。

我們收集的資料（匿名使用統計）

為了找出問題，並讓應用程式在更多電腦上跑得更快，電腦應用程式會傳送以下技術資訊：

  • 安裝時產生的隨機代碼，與你本人無關（只用來計算安裝次數而不重複）。
  • Pop3D 與 Windows 的版本、系統與應用程式的語言。
  • 顯示卡型號、顯示記憶體、驅動程式版本、處理器和記憶體（RAM）。
  • 效能結果：每秒影格數、顯示卡使用率和所選的畫質。
  • 應用程式的使用方式：頭戴裝置與連線類型（Wi-Fi、線材、PC VR）、影片模式（2D、3D、電腦螢幕）、使用時間。
  • 安裝步驟和錯誤訊息（不含檔案或資料夾名稱）。發生錯誤或影片卡住時，會一併傳送應用程式技術記錄的最後幾行，並在離開電腦前先清理過：不含電影、檔案或資料夾名稱、電子郵件或 IP 位址。

這些資料由分析服務 PostHog 儲存在歐盟境內的伺服器，只有 Pop3D 團隊能查看。我們不會出售或與任何人分享這些資料，也不會用於廣告。

你傳給我們的建議

在應用程式的 Ideas & feedback 中，你可以傳訊息給我們。除了你寫的內容，還會附上應用程式版本和你的顯示卡型號。電子郵件是選填的：只有在你填寫時才會傳送，而且只用來回覆你的訊息。建議和統計資料存放在同一個服務（PostHog，歐盟）。即使關閉統計，建議仍會傳送，因為是你自己決定要傳的。

如何關閉

在電腦應用程式中打開 Settings（設定），關閉 Send anonymous usage data。之後就不會再傳送任何資料（你自己選擇傳送的建議除外）。

更新

Pop3D 開啟時會查詢 GitHub（發布版本的地方），看看是否有新版本。就像任何網站一樣，GitHub 在那一刻會收到你電腦的網路位址；這項查詢適用 GitHub 的隱私權政策。不會附帶你的任何資訊。

頭戴裝置應用程式（Meta Quest）

頭戴裝置上的 Pop3D 應用程式不會收集資料，也不會傳送任何資料到網際網路。它只在你的區域網路中和你的電腦溝通，用來接收影片和傳送控制器的操作。

兒童

Pop3D 不會收集任何人的個人資料，包括兒童。請遵守頭戴裝置製造商的年齡建議。

你的權利（GDPR 與 LGPD）

由於統計資料是匿名的，我們無法把它和你連結起來。即使如此，如果你希望我們刪除你電腦的統計資料或你傳送的建議，請透過下方連結聯絡我們，並提供 Settings 中顯示的安裝代碼。

本政策的變更

如果本政策有所變更，新版本會連同更新日期顯示在這個頁面。
