隐私政策

更新日期 2026年10月2日

摘要：你的电影和视频永远不会离开你的电脑。Pop3D 只会发送匿名的使用统计（例如显卡型号和性能），帮助我们改进应用，你也可以随时在设置中关闭。

关于我们

Pop3D 是一款免费应用，能把 2D 视频转成 VR 头显用的 3D。它包括电脑应用（Windows）和头显应用（Meta Quest），本政策适用于两者。

我们绝不收集的信息

  • 你的电影和视频的名称、内容或画面，以及电脑屏幕上显示的任何内容。
  • 你电脑上的文件夹和文件名称。
  • 你的姓名、账号、联系人或任何能识别你的信息（电子邮件地址仅在你自己写进建议时才会发送；见下文）。
  • 你的 IP 地址：不会被保存，也不会用来判断你在哪里。
  • 摄像头画面、你周围的环境或头显的动作。

所有处理都在你自己的电脑上完成。视频通过局域网（Wi-Fi 或数据线）从电脑传到头显，绝不经过互联网。

我们收集的信息（匿名使用统计）

为了发现问题，并让应用在更多电脑上运行得更快，电脑应用会发送以下技术信息：

  • 安装时生成的随机代码，与你本人无关（仅用于统计安装数量，避免重复）。
  • Pop3D 和 Windows 的版本，系统和应用的语言。
  • 显卡型号、显存、驱动版本、处理器和内存。
  • 性能结果：每秒帧数、显卡占用率和所选画质。
  • 应用的使用方式：头显和连接方式（Wi-Fi、数据线、PC VR）、视频模式（2D、3D、电脑屏幕）、使用时长。
  • 安装步骤和错误信息（不含文件或文件夹名称）。发生错误或视频卡住时，会一并发送应用技术日志的最后几行，并在离开电脑前清理：不含电影、文件或文件夹名称，也不含电子邮件地址或 IP 地址。

这些数据由分析服务 PostHog 存储在欧盟境内的服务器上，只有 Pop3D 团队可以查看。我们不会出售或与任何人分享这些数据，也不会用于广告。

你发给我们的建议

在应用的 想法与反馈 中，你可以给我们发消息。除了你写的内容，还会附上应用版本和你的显卡型号。电子邮件是选填的：只有在你填写时才会发送，而且只用于回复你的消息。建议与统计数据存放在同一服务中（PostHog，欧盟）。即使关闭了统计，建议仍会发送，因为是你自己决定要发的。

如何关闭

在电脑应用中打开 设置，关闭 发送匿名使用数据。之后就不会再发送任何数据（你自己选择发送的建议除外）。

更新

Pop3D 打开时会访问 GitHub（发布版本的地方），查看是否有新版本。和任何网站一样，GitHub 在那一刻会收到你电脑的网络地址；这项检查适用 GitHub 的隐私政策。不会附带你的任何信息。

头显应用（Meta Quest）

Pop3D 头显应用不收集任何数据，也不会向互联网发送任何内容。它只在局域网中与你的电脑通信，用来接收视频并发送手柄操作。

儿童

Pop3D 不会收集任何人的个人信息，包括儿童。请遵守头显制造商的年龄建议。

你的权利（GDPR 与 LGPD）

由于统计数据是匿名的，我们无法把它与你联系起来。即便如此，如果你希望我们删除你电脑的统计数据或你发送的建议，请通过下方链接联系我们，并提供设置中显示的安装代码。

本政策的变更

如果本政策有变更，新版本会连同更新日期显示在本页面。
