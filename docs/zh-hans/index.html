常见问题

真的免费吗？

是的。没有广告，没有订阅，没有套路。

需要先转换视频吗？

不需要。直接播放：3D 在观看时实时生成。

需要在头显上安装什么吗？

不是必需的。最简单的是 Quest 版 Pop3D 应用，在 Meta 商店免费提供。如果你愿意，Pop3D 也支持 Steam Link、Air Link、Virtual Desktop 和 SteamVR。

我只装了 Quest 应用，接下来呢？

Quest 应用显示的是电脑上的 Pop3D 准备好的画面。请也在 Windows 电脑上安装 Pop3D：两边都打开后，头显会自动找到电脑。

安装快吗？

第一次安装时，Pop3D 会下载约 4 GB：这是施展魔法的人工智能，会针对你的显卡进行调整。所需时间取决于你的网速。之后应用几秒就能打开，并会自动更新。

能用在流媒体服务上吗？

电脑屏幕上显示的内容都可以，比如 YouTube 和大多数网站。部分付费服务会为视频加上防复制保护，不允许任何程序捕获画面。电脑里的视频可以直接使用。

没有 NVIDIA 显卡能用吗？

目前，魔法需要 NVIDIA RTX 显卡。如果你的电脑没有，安装程序会在一开始、下载任何东西之前就告诉你。

我的视频会离开我的电脑吗？

永远不会。一切都在你的电脑上完成，视频通过家庭网络直接传到头显。Pop3D 只会发送匿名使用统计，用来不断改进，你也可以在设置中关闭。请参阅隐私政策。

应用有简体中文吗？

有！Pop3D 支持简体中文：电脑应用、头显和安装程序都是中文。它会跟随 Windows 的语言，你也可以在 设置 › Pop3D 的语言 中更改。

Windows 显示“Windows 已保护你的电脑”，怎么办？

这是 Windows 对 Microsoft 还不认识的新程序显示的标准警告。请点更多信息，再点仍要运行。

我对 Pop3D 有个想法！

太好了！在应用的 想法与反馈 中就能直接发给我们。Pop3D 刚刚诞生，会和使用它的人一起成长。
