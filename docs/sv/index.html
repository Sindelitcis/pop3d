Pop3D-appen för Meta Quest

Hämta i Meta Horizon Store

Om du vill kan du också installera via en USB-kabel:

  1. Öppna appen Meta Horizon i mobilen och slå på Developer Mode (utvecklarläge) under Devices › Headset settings. Meta kräver ett utvecklarkonto, som är gratis.
  2. Anslut din Quest till datorn med en USB-kabel.
  3. Öppna Settings › Headset i Pop3D på datorn, klicka på Install on Quest och tryck på Allow i headsetet. Klart!

Vanliga frågor

Är det verkligen gratis?

Ja. Ingen reklam, ingen prenumeration, inga dolda villkor.

Måste jag konvertera mina videor först?

Nej. Tryck bara på play: 3D-effekten skapas medan du tittar.

Behöver jag installera något i headsetet?

Det är valfritt. Pop3D-appen för Quest är det enklaste sättet: den är gratis i Metas butik. Om du vill fungerar Pop3D också med Steam Link, Air Link, Virtual Desktop och SteamVR.

Jag har bara installerat Quest-appen. Vad gör jag nu?

Quest-appen visar det som Pop3D på din dator förbereder. Installera också Pop3D på din Windows-dator: när båda är öppna hittar headsetet datorn själv.

Går installationen snabbt?

Första gången laddar Pop3D ner cirka 4 GB: det är den artificiella intelligensen som skapar magin, och den anpassas till ditt grafikkort. Hur lång tid det tar beror på din internetanslutning. Sedan öppnas appen på några sekunder och uppdaterar sig själv.

Fungerar det med streamingtjänster?

Det fungerar med allt som visas på datorskärmen, som YouTube och de flesta webbplatser. Vissa betaltjänster skyddar sina videor mot kopiering och låter inget program fånga bilden. Videor på din dator fungerar direkt.

Fungerar det utan ett NVIDIA-kort?

Än så länge kräver magin ett NVIDIA RTX-grafikkort. Om din dator inte har ett säger installationsprogrammet det direkt i början, innan något laddas ner.

Lämnar mina videor någonsin datorn?

Aldrig. Allt sker på din dator, och videon går direkt till headsetet via ditt hemnätverk. Pop3D skickar bara anonym användningsstatistik för att fortsätta bli bättre, och du kan stänga av det under Settings (inställningar). Läs integritetspolicyn.

Finns appen på svenska?

Webbplatsen gör det, men Pop3D-appen visas på engelska tills vidare.

Windows visade ”Windows skyddade datorn”. Vad gör jag?

Det är Windows standardvarning för nya program som Microsoft inte känner till än. Klicka på Mer information och sedan på Kör ändå.

Jag har en idé till Pop3D!

Härligt! I appen, under Ideas & feedback, kan du skicka den direkt till oss. Pop3D är helt nytt och växer tillsammans med dem som använder det.

Redo att se allt i 3D?

Gratis. Installerar sig själv. Fungerar i ditt headset.
