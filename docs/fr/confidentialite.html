Politique de confidentialité

Mise à jour le 2 octobre 2026

En bref : vos films et vidéos ne quittent jamais votre ordinateur. Pop3D envoie uniquement des statistiques d'utilisation anonymes (comme le modèle de la carte graphique et les performances) pour que nous puissions améliorer l'app, et vous pouvez les désactiver à tout moment dans les Réglages.

Qui sommes-nous

Pop3D est une application gratuite qui transforme les vidéos 2D en 3D pour les casques de réalité virtuelle. Elle se compose de l'application pour ordinateur (Windows) et de l'application pour casque (Meta Quest). Cette politique s'applique aux deux.

Ce que nous ne collectons jamais

  • Les noms, contenus ou images de vos films et vidéos, ni ce qui s'affiche sur l'écran de votre ordinateur.
  • Les noms des dossiers et fichiers de votre ordinateur.
  • Votre nom, vos comptes, vos contacts ou toute donnée qui vous identifie (l'e-mail uniquement si vous l'écrivez vous-même dans une suggestion ; voir plus bas).
  • Votre adresse IP : elle n'est ni conservée ni utilisée pour savoir où vous vous trouvez.
  • Les images des caméras, de votre environnement ou des mouvements du casque.

Tout le traitement se fait sur votre propre ordinateur. La vidéo passe de l'ordinateur au casque par votre réseau local (Wi-Fi ou câble), sans passer par internet.

Ce que nous collectons (statistiques d'utilisation anonymes)

Pour détecter les problèmes et rendre l'app plus rapide sur plus d'ordinateurs, l'application pour ordinateur envoie des informations techniques comme :

  • Un code aléatoire créé à l'installation, sans lien avec vous (il sert seulement à compter les installations sans doublon).
  • Les versions de Pop3D et de Windows, la langue du système et de l'app.
  • Le modèle de la carte graphique, la mémoire vidéo, la version du pilote, le processeur et la mémoire vive.
  • Les résultats de performances : images par seconde, utilisation de la carte graphique et qualité choisie.
  • La façon dont l'app est utilisée : type de casque et de connexion (Wi-Fi, câble, PC VR), mode vidéo (2D, 3D, écran du PC), durée d'utilisation.
  • Les étapes de l'installation et les messages d'erreur (sans noms de fichiers ni de dossiers). Lorsqu'une erreur se produit ou que la vidéo se bloque, les dernières lignes du journal technique de l'app sont jointes, nettoyées avant de quitter l'ordinateur : sans noms de films, de fichiers, de dossiers, d'e-mails ni d'adresses IP.

Ces données sont conservées par PostHog, un service de statistiques, sur des serveurs situés dans l'Union européenne, et ne sont consultées que par l'équipe de Pop3D. Nous ne vendons ni ne partageons ces données avec personne, et nous ne les utilisons pas pour de la publicité.

Les suggestions que vous nous envoyez

Dans Idées et suggestions, dans l'app, vous pouvez nous envoyer un message. Avec le texte que vous écrivez sont envoyés la version de l'app et le modèle de la carte graphique. L'e-mail est facultatif : il n'est envoyé que si vous le remplissez, et sert uniquement à vous répondre. Les suggestions sont conservées dans le même service que les statistiques (PostHog, Union européenne). Elles sont envoyées même si les statistiques sont désactivées, car c'est vous qui décidez de les envoyer.

Comment désactiver

Dans l'application pour ordinateur, ouvrez les Réglages et désactivez Envoyer des données d'utilisation anonymes. À partir de là, plus rien n'est envoyé (sauf les suggestions que vous choisissez d'envoyer).

Mises à jour

À l'ouverture, Pop3D consulte GitHub (où les versions sont publiées) pour savoir si une nouvelle version est sortie. Comme n'importe quel site, GitHub reçoit alors l'adresse internet de votre ordinateur ; la politique de confidentialité de GitHub s'applique à cette consultation. Aucune information vous concernant n'est envoyée avec.

Application du casque (Meta Quest)

L'application Pop3D du casque ne collecte ni n'envoie aucune donnée sur internet. Elle communique uniquement avec votre ordinateur, sur votre réseau local, pour recevoir la vidéo et envoyer les commandes des manettes.

Enfants

Pop3D ne collecte de données personnelles sur personne, y compris les enfants. Suivez les recommandations d'âge du fabricant de votre casque.

Vos droits (RGPD et LGPD)

Comme les statistiques sont anonymes, nous ne pouvons pas les relier à vous. Malgré tout, si vous souhaitez que nous supprimions les statistiques de votre ordinateur ou une suggestion que vous avez envoyée, contactez-nous via le lien ci-dessous en indiquant le code d'installation affiché dans les Réglages.

Modifications de cette politique

Si cette politique change, la nouvelle version apparaîtra sur cette page avec la date mise à jour.
